# 🤝 Cómo contribuir a Komuny Edu

¡Gracias por querer contribuir! Este proyecto crece con la comunidad educativa latinoamericana.

---

## Formas de contribuir

### 📖 Agregar un término al glosario
1. Edita `glosario/glosario-ia-docentes.md`
2. Sigue el formato existente (término, definición, ejemplo, consejo docente si aplica)
3. Abre un Pull Request

### 🤖 Compartir un skill
1. Crea un archivo `.md` en `skills/`
2. Nombre: `skill-[nombre-descriptivo].md`
3. Incluye: propósito, instrucciones, ejemplo de uso

### 📝 Escribir una guía
1. Crea un archivo en `guides/`
2. Basate en tu experiencia real en el aula

### 🎫 Agregar un template
1. Crea un archivo en `templates/`
2. Incluye el prompt completo y listo para copiar

### 🐛 Reportar un error
Abre un [Issue](https://github.com/german-gimenez/komuny/issues/new) describiendo el problema.

---

## Formato para términos del glosario

```markdown
**Nombre del término**
Definición clara y sin tecnicismos.
*Ejemplo en el aula:* Descripción práctica de uso.
*Consejo docente:* Tip útil para aplicarlo.
```

---

## Código de conducta

Este es un espacio respetuoso y colaborativo. Tratamos a todos con respeto, independientemente de su nivel técnico o país de origen.
