# Komuny para Fundaciones

> **Llevamos Komuny Chat a tu fundacion**, sin que construyan desde cero.
> Stack educativo open source para fundaciones de LATAM.
> Hecho con [Anthropic](https://anthropic.com), desarrollado por [Napsix.AI](https://napsix.ai).

Web: [komuny.org/para-fundaciones](https://komuny.org/para-fundaciones)

---

## ¿Para que fundaciones es?

- Fundaciones educativas que **capacitan docentes** y necesitan dar
  herramientas IA practicas a su comunidad
- Organizaciones sociales con **programas de becas o tutorias**
- ONGs con **componentes educativos** en sus proyectos
- Fundaciones **corporativas** con linea de educacion
- Organismos regionales de **formacion docente continua**

---

## ¿Que ofrecemos?

### 1. Chat con tu marca (white-label)
- Logo, colores, dominio propio (`chat.tu-fundacion.org`)
- Footer institucional
- Branding completo: el chat se ve como **suyo**, no como nuestro

### 2. Presets a medida
Mas alla de los [6 presets pedagogicos](komuny-chat-para-fundaciones.md#presets-incluidos)
incluidos por defecto, disenamos asistentes especificos para:
- Tu programa social concreto
- Tu region o idioma
- Tu nivel educativo
- Tu metodologia pedagogica

### 3. Acompanamiento Napsix.AI
- Implementacion tecnica
- Capacitacion del equipo
- Soporte continuo
- Consultoria pedagogica

### 4. Modelos Anthropic
- **Claude Opus 4.6** y **Sonnet 4.6** como motor IA
- Disenados con foco en seguridad y alineamiento
- Especialmente apropiados para contextos educativos
- Programa [Anthropic for Nonprofits](https://claude.com/solutions/nonprofits) disponible

### 5. Contenido Komuny incluido
Al adoptar Komuny Chat, tu fundacion accede a todo el contenido open source:
- 30+ terminos del glosario IA para docentes
- 7 skills para Claude
- 7 guias pedagogicas
- Templates de prompts en espanol
- Recursos curados

### 6. Privacidad y soberania
- Hosting en **tu region** (la nube que tu fundacion elija)
- Control sobre datos y retencion
- **SSO/SAML** para integracion con tus sistemas
- Tus conversaciones **no se usan para entrenar modelos**

## Stack tecnico transparente

| Capa | Tecnologia | Por que |
|------|-----------|---------|
| Frontend del Chat | [LibreChat](https://github.com/danny-avila/LibreChat) | Open source, auditable, 36k stars |
| Motor IA | Claude Opus 4.6 / Sonnet 4.6 | Modelos mas seguros y alineados |
| Hosting | Vercel / Cloudflare / AWS | Tu eleccion regional |
| Auth | OAuth, SAML, SSO | Integracion con tus sistemas |
| Datos | PostgreSQL / MongoDB | En tu region |
| Operacion | Napsix.AI | Implementacion + soporte |

Sin caja negra. Sabes exactamente que esta corriendo y donde.

## Modelo de costos

El modelo es **proporcional al uso** + un **acompanamiento Napsix.AI** mensual.

**Componentes:**
- Creditos de Anthropic (modelos Claude) — pagas por uso real de tokens
- Hosting Vercel/Cloudflare/AWS — bajo costo, escalable
- Setup inicial Napsix.AI — implementacion + branding + presets a medida
- Soporte mensual Napsix.AI — operacion, mejoras, soporte tier 1

Pedinos una propuesta concreta segun tu fundacion: numero de usuarios estimados,
horarios de uso, presets a medida que necesites.
