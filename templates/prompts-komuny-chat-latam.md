# 12 Prompts listos para Komuny Chat - LATAM

Prompts curados para docentes de America Latina, listos para copiar/pegar
en https://chat.komuny.org. Cada prompt indica que asistente usar (preset).

> **Tip:** En tu perfil podes guardar tu pais y nivel educativo. La IA
> usara terminologia y referencias curriculares de tu region cuando lo necesites.

---

## 1. Planificacion de clases

### Prompt 1 - Secuencia didactica de una clase
**Asistente:** Planificador de Clases

```
Diseña una secuencia didactica para una clase de [MATERIA] de [NIVEL EDUCATIVO]
sobre el tema [TEMA]. Duracion: [MINUTOS] minutos.

Objetivo de aprendizaje principal: [OBJETIVO]

Estructura solicitada:
- Inicio motivador (10-15 min)
- Desarrollo con actividad practica (20-30 min)
- Cierre con metacognicion (10 min)

Incluye recursos necesarios y al menos 2 adaptaciones para diversidad.
```

### Prompt 2 - Plan de unidad de 2 semanas
**Asistente:** Planificador de Clases

```
Diseña un plan de unidad de 2 semanas (10 clases) sobre [TEMA] para
[NIVEL EDUCATIVO] - [MATERIA].

Contexto: clases de 80 minutos, grupo de [N] estudiantes.

Producto final esperado: [DESCRIBIR].

Incluye:
- Mapa conceptual de la unidad
- Distribucion de contenidos por clase
- 3 momentos evaluativos (diagnostico, formativo, sumativo)
- Cronograma sugerido
```

## 2. Evaluacion

### Prompt 3 - Rubrica de evaluacion
**Asistente:** Generador de Rubrica

```
Necesito una rubrica de evaluacion para [PRODUCTO/ACTIVIDAD] en [MATERIA]
de [NIVEL EDUCATIVO].

Objetivo de aprendizaje a evaluar:
[OBJETIVO]

Estructura:
- 4 criterios (puede ser: contenido, organizacion, expresion, originalidad)
- 4 niveles de desempeño (Inicial / En desarrollo / Logrado / Destacado)
- Descriptores observables por nivel
- Sugerencia de retroalimentacion para cada nivel
```

### Prompt 4 - Examen estructurado por niveles Bloom
**Asistente:** Banco de Preguntas Bloom

```
Diseña un examen sobre [TEMA] para [NIVEL EDUCATIVO] - [MATERIA].

Duracion: [MINUTOS] minutos
Distribucion sugerida: 70% preguntas de comprension/aplicacion,
30% analisis/evaluacion/creacion.

Incluye:
- 5 preguntas de opcion multiple (Recordar/Comprender)
- 3 preguntas de desarrollo corto (Aplicar/Analizar)
- 1 problema integrador (Evaluar/Crear)
- Pauta de correccion sugerida con puntajes
```

## 3. Comunicacion con familias

### Prompt 5 - Boletin informativo del bimestre
**Asistente:** Asistente Komuny

```
Necesito redactar un boletin para familias informando sobre el cierre del
[BIMESTRE/TRIMESTRE/SEMESTRE] en [MATERIA] - [NIVEL EDUCATIVO].

Temas trabajados en este periodo:
- [TEMA 1]
- [TEMA 2]
- [TEMA 3]

Tono: calido, claro, accesible para familias con distinto nivel educativo.
Extension: 1 pagina maximo.

Incluye:
- Saludo personal
- Logros del grupo (en general)
- Recomendaciones para acompañar desde casa
- Avisos importantes proximos
- Datos de contacto
```

### Prompt 6 - Comunicacion ante situacion especifica
**Asistente:** Asistente Komuny

```
Necesito comunicar a la familia de un estudiante una situacion delicada:
[DESCRIBIR SITUACION DE FORMA ANONIMA - usa 'el estudiante' o iniciales].

Contexto:
- Edad del estudiante: [EDAD]
- Tipo de situacion: [ACADEMICA / CONDUCTUAL / EMOCIONAL / SOCIAL]
- Que necesito que la familia haga: [ACCION ESPERADA]

Redacta un mensaje:
- Empatico, no acusatorio
- Centrado en el bienestar del estudiante
- Concreto sobre proximos pasos
- Que invite al dialogo, no a la defensa
- Extension: corta, max 200 palabras

NO ingreses datos personales del estudiante. Anonimizar siempre.
```

## 4. Adaptacion de contenidos

### Prompt 7 - Simplificar texto para lectura inicial
**Asistente:** Simplificador de Textos

```
Adapta el siguiente texto para estudiantes de [NIVEL LECTOR / EDAD].

Texto original:
[PEGAR TEXTO]

Necesito:
- Vocabulario apropiado al nivel
- Frases cortas (max 15-20 palabras)
- Glosario de 5-8 terminos clave al final
- 3 preguntas de comprension lectora
- Sugerencia de actividad post-lectura (10 min)
```

### Prompt 8 - Adaptar material para diversidad
**Asistente:** Asistente Komuny

```
Tengo este material/actividad para una clase de [MATERIA] - [NIVEL EDUCATIVO]:

[DESCRIBIR ACTIVIDAD ORIGINAL]

Necesito 3 versiones adaptadas para:
1. Estudiante con dislexia
2. Estudiante neurodivergente (TDAH)
3. Estudiante con español como segunda lengua

Para cada version indica:
- Que se mantiene del original
- Que se modifica
- Recursos extra necesarios
- Como evaluar el mismo objetivo de aprendizaje
```

## 5. Revision critica

### Prompt 9 - Detectar sesgos en material didactico
**Asistente:** Detector de Sesgos

```
Analiza el siguiente material didactico para detectar sesgos involuntarios:

[PEGAR TEXTO / DESCRIBIR ACTIVIDAD]

Categorias a revisar:
- Genero (lenguaje, representacion, roles)
- Cultural y regional (eurocentrismo, urbano-rural)
- Socioeconomico (asumir contexto)
- Capacidades (capacitismo)
- Etario (adultocentrismo)

Devuelve:
1. Resumen ejecutivo (3 lineas)
2. Sesgos detectados con fragmento + propuesta de mejora
3. Version reescrita sugerida
4. Recomendaciones para futuras producciones
```

### Prompt 10 - Analisis curricular con perspectiva critica
**Asistente:** Detector de Sesgos

```
Estoy planificando una unidad sobre [TEMA HISTORICO/SOCIAL/CULTURAL] para
[NIVEL EDUCATIVO].

Analiza con perspectiva critica latinoamericana:
- Voces tradicionalmente excluidas en este tema
- Perspectivas no occidentales relevantes
- Conexion con derechos humanos / ESI / ambiente
- Como abordar controversias actuales

Sugiere 5 recursos o referentes alternativos a los canonicos.
```

## 6. Reflexion pedagogica

### Prompt 11 - Diario docente - reflexion post clase
**Asistente:** Asistente Komuny

```
Acabo de dar una clase y necesito reflexionar sobre ella. Te cuento que paso:

[DESCRIBIR LA CLASE: que planifique, que salio bien, que no funciono,
que me sorprendio, que estudiante necesita mas atencion - SIN nombres]

Ayudame a:
1. Identificar 2 momentos clave (positivos y/o de mejora)
2. Pensar 1 ajuste concreto para la proxima clase
3. Formular 1 pregunta de investigacion docente
4. Reconocer 1 logro personal de hoy (autocuidado)
```

### Prompt 12 - Devolucion personalizada anonimizada
**Asistente:** Asistente Komuny

```
Necesito redactar una devolucion personalizada para un estudiante.
Te paso el contexto SIN datos personales:

- Edad: [EDAD]
- Nivel: [NIVEL EDUCATIVO]
- Materia: [MATERIA]
- Trabajo evaluado: [DESCRIPCION CORTA]
- Logros del estudiante: [DESCRIBIR]
- Areas a mejorar: [DESCRIBIR]
- Recomendacion principal: [TU OBSERVACION]

Tono: alentador, especifico, constructivo. Max 150 palabras.

Estructura: empezar reconociendo un logro -> señalar area de mejora con
una sugerencia concreta -> cerrar con confianza en su proceso.
```

## Tips para usar bien los prompts

1. **Reemplaza los [PLACEHOLDERS]** con info real (anonimizada cuando sea de estudiantes)
2. **Empieza con el preset correcto** - el indicado al inicio de cada prompt
3. **Iterativa** - si la primera respuesta no es exacta, pedi ajustes ("hazlo mas corto", "agrega un ejemplo")
4. **Verifica siempre** - lo que genere la IA es punto de partida, no producto final
5. **Compartir prompts propios** - si creas uno bueno, mandanoslo a hola@komuny.org
