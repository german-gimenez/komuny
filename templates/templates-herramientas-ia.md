# Templates para las Herramientas IA de Komuny Edu

> Usa estos templates como punto de partida en las herramientas web de Komuny.
> Accede en: [komuny.org/herramientas](https://komuny.org/herramientas)

---

## Templates para el Generador de Rubrica

### Template 1: Rubrica para presentacion oral (secundaria)
```
Materia: La que necesites
Nivel: Secundaria
Tipo: Presentacion oral / Exposicion
Criterios: claridad en la exposicion, dominio del tema, uso de recursos visuales, 
           manejo del tiempo, capacidad para responder preguntas
```

### Template 2: Rubrica para proyecto grupal (universitario)
```
Materia: La que necesites
Nivel: Universitario
Tipo: Proyecto grupal
Criterios: distribucion equitativa del trabajo, calidad del producto final, 
           fundamentacion teorica, originalidad, presentacion escrita
```

### Template 3: Rubrica para ensayo argumentativo (bachillerato)
```
Materia: Lengua / Ciencias Sociales
Nivel: Bachillerato/Polimodal
Tipo: Trabajo escrito / Ensayo
Criterios: tesis clara, argumentos fundamentados, uso de fuentes, 
           coherencia textual, conclusion solida
```

## Templates para el Planificador de Clases

### Template 1: Clase introductoria (45 min, presencial)
```
Tema: El tema especifico de tu clase
Materia: Tu materia
Nivel: Secundaria basica
Duracion: 45 minutos
Modalidad: Presencial
Objetivos: que los estudiantes puedan identificar los conceptos clave 
           y conectarlos con su experiencia cotidiana
Recursos: pizarron, marcadores, cuadernos
```

### Template 2: Clase practica (80 min, hibrida)
```
Tema: Tu tema de aplicacion practica
Materia: Tu materia
Nivel: Bachillerato/Polimodal
Duracion: 80 minutos
Modalidad: Hibrida
Objetivos: aplicar los conocimientos teoricos en situaciones reales, 
           desarrollar habilidades de trabajo colaborativo
Recursos: proyector, computadoras o celulares, materiales fisicos
```

### Template 3: Clase de cierre/evaluacion (60 min)
```
Tema: Repaso y cierre de [unidad o tema]
Materia: Tu materia
Nivel: El que corresponda
Duracion: 60 minutos
Modalidad: Presencial
Objetivos: consolidar los aprendizajes del periodo, identificar dudas 
           pendientes, realizar evaluacion formativa
```

## Templates para el Banco de Preguntas (Bloom)

### Template 1: Banco para texto literario (primaria)
```
Tema: [Nombre del cuento o texto + pegar un fragmento clave]
Nivel: Primaria (4-6)
Cantidad por nivel: 1 pregunta
Tipo: Mixto
```

### Template 2: Banco para unidad historica (secundaria)
```
Tema: [Nombre de la unidad o epoca historica + conceptos clave]
Nivel: Secundaria basica
Materia: Historia
Cantidad por nivel: 2 preguntas
Tipo: Abiertas
```

### Template 3: Banco para clase de ciencias (universitario)
```
Tema: [Texto del articulo cientifico o descripcion del tema]
Nivel: Universitario
Materia: La correspondiente
Cantidad por nivel: 3 preguntas
Tipo: Mixto (abiertas y cerradas)
```

## Como usar estos templates

1. Ve a [komuny.org/herramientas](https://komuny.org/herramientas)
2. Elige la herramienta que necesites
3. Copia el template correspondiente y adaptalo a tu caso
4. Completa los campos en el formulario
5. Haz clic en Generar
6. Revisa y ajusta el resultado a tu contexto
