# 🎫 Templates de Prompts para Docentes

Copia y pega cualquiera de estos prompts directamente en Claude.ai

## 📋 PLANIFICACIÓN

### Ticket: Plan de clase completo
```
Soy docente de [MATERIA] para [NIVEL/GRADO].
Necesito un plan de clase sobre [TEMA].
Duración: [X] minutos.
Materiales disponibles: [lista o "básicos solamente"].
Genera el plan con: objetivo, apertura, desarrollo, cierre y evaluación.
```

### Ticket: Secuencia didáctica semanal
```
Crea una secuencia de 5 clases sobre [TEMA] para [NIVEL].
Cada clase dura [X] minutos.
El objetivo final es que los alumnos puedan [OBJETIVO].
Incluye progresión de dificultad y conexión entre clases.
```

## ✏️ EVALUACIÓN

### Ticket: Generador de rúbrica
```
Crea una rúbrica de evaluación para [TIPO DE TRABAJO: ensayo/proyecto/presentación].
Nivel: [GRADO/NIVEL].
Criterios a evaluar: [lista o "los que consideres relevantes"].
Escala: [1-4 / A-D / Insuficiente-Excelente].
Formato: tabla clara y fácil de usar.
```

### Ticket: Banco de preguntas
```
Genera 10 preguntas sobre [TEMA] para [NIVEL].
Incluye:
- 3 preguntas de comprensión básica
- 4 preguntas de análisis
- 3 preguntas de aplicación práctica
Formato múltiple opción con respuesta correcta marcada.
```

### Ticket: Feedback para trabajos
```
Necesito dar retroalimentación constructiva a un alumno sobre su [TRABAJO].
El alumno tiene [EDAD/NIVEL].
Aspectos positivos: [lista].
Aspectos a mejorar: [lista].
Escribe el feedback en tono alentador, claro y específico. Máximo 150 palabras.
```

## 💬 COMUNICACIÓN

### Ticket: Mensaje para padres/familias
```
Redacta un mensaje para enviar a las familias sobre [TEMA/SITUACIÓN].
Tono: [formal/cercano].
Puntos a incluir: [lista].
Extensión: máximo [X] líneas.
Evita tecnicismos educativos.
```

### Ticket: Adaptación de contenido
```
Tengo este texto/explicación: [PEGA AQUÍ EL TEXTO].
Necesito adaptarlo para alumnos de [NIVEL] con [CONTEXTO: dificultades de lectura / avanzados / NEE].
Mantén las ideas principales pero ajusta vocabulario y estructura.
```

---

## 🧠 DIFERENCIACIÓN

### Ticket: Adaptar para NEE
```
Tengo esta actividad: [DESCRIBE LA ACTIVIDAD].
Necesito adaptarla para un alumno con [NECESIDAD ESPECÍFICA].
Mantén el mismo objetivo de aprendizaje pero ajusta la forma de trabajarlo.
```

### Ticket: Enriquecimiento para alumnos avanzados
```
Tengo alumnos que ya dominan [TEMA]. 
Sugiere 3 actividades de profundización o extensión que los desafíen
sin que queden desconectados del grupo clase.
Nivel: [GRADO].
```
