# Guia 4: Adaptar contenidos para diversidad en el aula

**Nivel:** Intermedio
**Tiempo:** 30-40 minutos
**Herramienta:** Claude.ai
**Para:** Docentes con alumnos con NEE, diferentes ritmos de aprendizaje o contextos multiculturales

---

## El desafio de la diversidad en el aula

Un mismo texto, actividad o evaluacion no funciona igual para todos.
La IA puede ayudarte a adaptar tus materiales existentes en minutos, sin tener que
crear desde cero para cada situacion.

---

## Caso 1: Adaptar un texto para diferentes niveles lectores

Tenes un texto que queres usar en clase, pero algunos alumnos tienen dificultades de lectura.

```
Tengo este texto: [PEGA EL TEXTO AQUI]

Necesito dos versiones:
VERSION A: Para alumnos con dificultades de lectura (nivel primario bajo).
- Frases cortas (no mas de 10 palabras)
- Vocabulario simple, sin tecnicismos
- Una idea por parrafo
- Agrega una analogia sencilla para el concepto mas complejo

VERSION B: Para alumnos avanzados.
- Mantiene la complejidad del original
- Agrega 2 preguntas de analisis critico al final
- Sugiere una fuente adicional para profundizar
```

---

## Caso 2: Adaptar una actividad para un alumno con TEA

```
Tengo esta actividad de clase: [DESCRIPCION DE LA ACTIVIDAD]

Necesito adaptarla para un alumno con Trastorno del Espectro Autista (TEA).
El alumno tiene: [CARACTERISTICAS: dificultad con cambios / sensibilidad sensorial / etc]

La adaptacion debe:
- Mantener el mismo objetivo de aprendizaje
- Dividir la actividad en pasos numerados y visuales
- Eliminar ambiguedades (instrucciones claras y literales)
- Reducir estimulos distractores en la descripcion
- Agregar un ejemplo concreto para cada instruccion abstracta
```

---

## Caso 3: Actividad para alumno con discapacidad visual

```
Tengo esta actividad que incluye elementos visuales: [DESCRIPCION]

Adaptar para un alumno con discapacidad visual:
- Reemplaza las referencias visuales por descripciones tactiles o auditivas
- Indica que materiales alternativos se pueden usar (relieve, audio, etc)
- Ajusta las consignas para que sean 100% accesibles sin ver
```

---

## Caso 4: Adaptar para contexto rural o sin conectividad

```
Tengo esta actividad que requiere internet: [DESCRIPCION]

Necesito una version offline para alumnos sin conectividad.
Contexto: [DESCRIPCION DEL CONTEXTO: zona rural, acceso a fotocopias, etc]

La version offline debe:
- Mantener el objetivo de aprendizaje
- Usar solo materiales disponibles en el aula o en el hogar
- Proponer alternativas a los recursos digitales
- Ser realizable con papel, lapiz y lo que hay en el entorno
```

---

## Caso 5: Enriquecimiento para alumnos que van mas rapido

```
Mis alumnos avanzados ya terminaron la actividad antes que el resto.
Actividad original: [DESCRIPCION]
Tema: [TEMA]
Nivel: [GRADO]

Propone 3 actividades de extension que:
- Profundicen el mismo tema sin repetir lo que ya hicieron
- Puedan hacerse en silencio sin molestar al resto
- Representen un desafio real, no solo mas de lo mismo
- Conecten el tema con la realidad o problemas actuales
```

---

## Principio etico clave

La IA no conoce a tu alumno. Las adaptaciones que genera son puntos de partida.
Siempre revisa con la perspectiva de quien si conoce al alumno:
- Vos como docente
- El equipo de orientacion escolar
- La familia, cuando corresponda

**La IA reduce el tiempo de creacion. La decision pedagogica siempre es tuya.**
