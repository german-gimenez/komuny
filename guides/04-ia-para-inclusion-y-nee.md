# Guia 4: IA para docentes con alumnos con necesidades educativas especiales

**Nivel:** Intermedio - Avanzado
**Tiempo:** 30 minutos
**Herramienta:** Claude.ai o ChatGPT (gratuito)
**Ideal para:** Docentes de inclusion, maestros de apoyo, cualquier docente en aulas diversas

---

## Por que la IA es especialmente util para la inclusion?

La personalizacion del aprendizaje, clave en el enfoque DUA (Diseno Universal para el Aprendizaje), siempre fue costosa en tiempo para el docente. La IA cambia esto: adaptar un texto, simplificar una consigna o generar actividades diferenciadas ahora lleva minutos en lugar de horas.

---

## Principios DUA que la IA puede potenciar

| Principio DUA | Como ayuda la IA |
|--------------|-----------------|
| Multiples formas de representacion | Adapta textos, genera analogias, explica con diferentes niveles |
| Multiples formas de accion y expresion | Crea consignas alternativas, actividades orales, visuales o practicas |
| Multiples formas de motivacion | Conecta contenidos con intereses del alumno, genera contextos significativos |

## Adaptacion de textos y materiales

### Simplificar un texto complejo
```
Tengo este texto para alumnos de [NIVEL]:
[PEGA EL TEXTO AQUI]

Necesito adaptarlo para un alumno con dificultades de comprension
lectora. Por favor:
- Usa oraciones cortas (maximo 15 palabras)
- Vocabulario simple, sin terminos tecnicos sin explicar
- Agrega subtitulos para organizar las ideas
- Mantene las ideas principales del original
```

### Crear version con pictogramas o imagenes
```
Tengo esta consigna de trabajo:
[CONSIGNA ORIGINAL]

Reescribela de forma que pueda acompañarse de pictogramas.
- Frases muy cortas
- Una idea por oracion
- Verbos de accion claros (busca, escribe, marca, une)
- Indica con [IMAGEN] donde iria un pictograma y describe que imagen seria
```

### Adaptar para diferentes niveles en la misma clase
```
Tengo esta actividad sobre [TEMA]:
[DESCRIPCION DE LA ACTIVIDAD]

Crea 3 versiones de la misma actividad con el mismo objetivo
de aprendizaje pero diferente nivel de complejidad:
- Nivel basico: para alumnos que necesitan mas apoyo
- Nivel estandar: para la mayoria del grupo
- Nivel avanzado: para alumnos que terminan rapido y necesitan desafio
```

## Comunicacion con familias y equipos de apoyo

### Informe de progreso accesible
```
Necesito escribir un informe de progreso para las familias
de un alumno con [NEE ESPECIFICA].
El alumno ha logrado: [LOGROS]
Esta trabajando en: [ASPECTOS EN PROCESO]
Recomendaciones para casa: [IDEAS QUE TENGAS]

Escribe el informe en lenguaje claro, positivo y sin jerga tecnica.
Maximo una pagina. Tono calido y esperanzador.
```

### Email para el equipo interdisciplinario
```
Necesito comunicarme con el equipo de apoyo sobre el alumno [sin nombre, llama "el alumno"].
Situacion: [DESCRIPCION BREVE]
Lo que observe: [CONDUCTAS O DIFICULTADES CONCRETAS]
Lo que probe: [ESTRATEGIAS QUE YA INTENTE]
Lo que necesito: [QUE PIDES AL EQUIPO]

Redacta un email profesional, claro y centrado en soluciones.
```

## Estrategias para momentos especificos

### Para alumnos con TDAH: actividades con estructura clara
```
Tengo un alumno con TDAH en [NIVEL].
El tema de la clase es [TEMA].
La clase dura [X] minutos.

Diseña una secuencia de actividades que:
- Cambie de formato cada 10-12 minutos
- Incluya al menos un momento de movimiento o manipulacion
- Tenga instrucciones de maximo 2 pasos a la vez
- Incluya una tarea de cierre breve y concreta
```

### Para alumnos con TEA: anticipacion y rutinas
```
Tengo un alumno con autismo en mi clase.
Mañana vamos a hacer [ACTIVIDAD DIFERENTE A LA RUTINA].

Crea un texto de anticipacion en primera persona, simple y positivo,
que le pueda dar hoy para prepararle para mañana.
Incluye: que va a pasar, en que orden, cuanto dura cada momento,
y que va a pasar cuando termine.
```

### Para alumnos con dificultades de lectoescritura
```
Mi alumno tiene dislexia o dificultades de lectoescritura.
Necesito evaluar si comprendio [CONCEPTO] sin que la dificultad
de lectura sea un obstaculo.

Diseña 3 formas alternativas de evaluacion que no requieran
escritura extensa: pueden ser orales, graficas, de seleccion,
de completar, de ordenar, etc.
```

---

## Consejo clave

La IA no conoce a tu alumno. Vos si. Usa la IA para generar opciones rapidamente y luego elige, adapta y personaliza con tu criterio profesional. El docente siempre tiene la ultima palabra.
