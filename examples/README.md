# Ejemplos reales de docentes usando IA

> Esta carpeta recopila casos de uso reales de educadores latinoamericanos.
> ¿Tienes un caso para compartir? [Abre un issue](https://github.com/german-gimenez/komuny/issues/new)

---

## Cómo contribuir un ejemplo

Crea un archivo con este formato:

```markdown
# Caso: [Título descriptivo]

**Docente:** [Nombre o "Anónimo"]
**País:** [País]
**Nivel:** [Primaria / Secundaria / Universidad]
**Materia:** [Materia]

## El desafío
¿Qué problema querías resolver?

## Cómo lo usé
¿Qué prompt o skill usaste?

## El resultado
¿Qué obtuviste? ¿Funcionó?

## Lo que aprendí
Tips para otros docentes.
```
