## ¿Qué es Komuny Edu?

Komuny Edu es un repositorio open source creado por y para educadores de América Latina. Nació de una convicción simple: **la IA debe ser accesible para todos los docentes**, no solo para quienes saben programar.

Aquí encontrarás:
- 📖 **Glosario** — Términos de IA explicados sin tecnicismos
- 🤖 **Skills para Claude** — Configuraciones listas para tareas docentes
- 🎫 **Templates de prompts** — Tickets listos para copiar y usar
- 📚 **Guías paso a paso** — Cómo crear clases con IA
- 💡 **Ejemplos reales** — Casos de uso de docentes de la región
