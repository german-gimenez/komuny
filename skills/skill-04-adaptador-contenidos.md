# Skill 04: Adaptador de Contenidos y Materiales

**Proposito:** Transformar cualquier material existente para que sea accesible
a diferentes niveles, estilos de aprendizaje y necesidades especificas.

---

## Instruccion de sistema (System Prompt)

```
Eres un experto en diferenciacion pedagogica y adaptacion de materiales
educativos para contextos latinoamericanos.

Al adaptar contenidos:
- Conserva el objetivo de aprendizaje original
- Cambia SOLO lo necesario para hacerlo accesible
- Explicita los cambios que hiciste y por que
- Si el docente pega un texto, analizalo antes de adaptar
- Para simplificacion: usa el criterio de "lo entenderia un adulto
  sin estudios universitarios?"
- Para complejizacion: agrega capas de profundidad sin cambiar el nucleo
- Siempre menciona si necesitas mas contexto sobre el alumno o grupo
```

---

## Prompts de uso

### Simplificar un texto
```
Tengo este texto para alumnos de [NIVEL]:

[PEGA EL TEXTO AQUI]

Necesito simplificarlo para alumnos con dificultades de comprension lectora.
Por favor:
- Oraciones de maximo 15 palabras
- Reemplaza terminos tecnicos con explicaciones simples
- Agrega subtitulos para organizar las ideas
- Conserva las ideas principales
- Indica al final que cambios realizaste
```

### Adaptar para diferentes niveles en la misma clase
```
Tengo esta actividad:
[DESCRIPCION O TEXTO DE LA ACTIVIDAD]

Necesito 3 versiones con el mismo objetivo de aprendizaje:
- Version A (apoyo): para alumnos que necesitan acompanamiento extra
- Version B (estandar): para la mayoria del grupo
- Version C (extension): para alumnos que necesitan un desafio mayor
Que cada version tenga las instrucciones claras y el mismo formato.
```

### Adaptar para distintos estilos de aprendizaje
```
Tengo este contenido sobre [TEMA]:
[DESCRIPCION DEL CONTENIDO]

Crea 3 actividades distintas que desarrollen el mismo aprendizaje
pero desde distintas entradas:
1. Visual: con esquema, mapa conceptual o infografia para completar
2. Cinetica/practica: con manipulacion, experimento o juego de roles
3. Lectura/escritura: con texto y preguntas de analisis
```

### Convertir texto en preguntas socraticas
```
Tengo este texto sobre [TEMA]:
[TEXTO]

Genera 8 preguntas socraticas que guien a los alumnos a descubrir
las ideas principales sin decirlas directamente.
Las preguntas deben ir de lo concreto a lo abstracto.
Nivel: [NIVEL]
```

### Actualizar un material viejo
```
Tengo esta actividad que use hace varios años:
[DESCRIPCION O TEXTO DE LA ACTIVIDAD]

Actualiza el contexto para que sea relevante y motivador para alumnos
de [AÑO ACTUAL], manteniendo el mismo objetivo pedagogico.
Que incluya referencias a situaciones, tecnologias o intereses actuales.
```

### Crear material desde cero para un tema dificil
```
Los alumnos de [NIVEL] tienen dificultad con [CONCEPTO ESPECIFICO].
El error tipico que cometen es: [DESCRIPCION DEL ERROR O CONFUSION]

Crea un material de 1 pagina que:
- Parte de algo que ya conocen bien
- Use una analogia o metafora para explicar el concepto
- Incluya 3 ejemplos del concepto en contextos cotidianos
- Tenga 3 preguntas de verificacion al final
```

## Adaptaciones especificas frecuentes

### Para alumnos con dislexia
```
Tengo esta consigna [CONSIGNA]. Reformulala para un alumno con dislexia:
- Frases cortas y directas
- Verbo de accion al inicio de cada instruccion
- Evita dobles negaciones y construcciones complejas
- Numera cada paso por separado
```

### Para alumnos avanzados que terminan rapido
```
Mis alumnos avanzados terminaron la actividad principal sobre [TEMA].
Necesito 3 actividades de extension desafiantes que puedan hacer
de forma autonoma mientras el resto termina.
Que conecten con el mismo tema pero que requieran pensamiento creativo
o investigacion.
```
